02

整体观感

Overall Impression

这张框架图的第一印象是「密而有序」：2874×1946 的画布里塞了三层信息，却靠一条粗灰虚线分节符把页面管得井井有条。与第 001、002 期相比，它的气质最像一份排版讲究的产品说明书——所有模块都是圆角矩形与胶囊，所有标签都是加粗衬线体，所有填充都是近白粉彩，唯一的实色只出现在主干板片（青蓝 #4B90BB）、证据照片和 MHA 的金色描边上。

全图真正的设计主角不是某个模块，而是光照：灰度渐变条在框架图里出现两次（顶部插图的底座、IWM 带的立方堆），又在数据集图里升格为整张图的列轴——论文的核心变量被做成贯穿全部图面的视觉母题（详见 §07）。这是本系列迄今第一次见到「方法变量即版式母题」的做法。

与 002 期 Fusion-Mamba 对照：同为 Office 系粉彩（金 #BF9000 也是 Office 深金原值），但 EI²Det 把填充压得更淡（多在 #EBF1DF–#FCEBDD 一带），把色彩权重移到描边（金边 MHA、彩边输出胶囊）和小 glyph（⊕、渐变立方堆）上；002 的语法核心是「芯片色即算子」，这里则是「形状即类别」——胶囊永远是 token、圆角矩形永远是模块、板片永远是特征。

03

逐图拆解

Figure by Figure

框架图 · 上带管线层

  • 双流严格镜像：VIS 行与 IR 行同构（照片 → 三级板片 → 热力图堆），VIS 板片青蓝、IR 板片中性灰，模态区分只靠板片一处颜色，其余全同。
  • CIMs 巨石盒：管线正中央立着一个占位极大的近白圆角盒，只写 "CIMs" 三个字——全图最大的图形元素承载最少的信息（见 §07 瑕疵）。
  • 证据插图挂中缝：IWM 与 EFM 两列之间、双流的正中缝里，上下各挂一张小图：一张是钟形概率曲线压在分段灰度渐变条上的「Illumination Level」，一张是街景的黑白边缘图「Edge Map」。每张插图用上下双向箭头同时喂给两条支路的 IWM/EFM 药丸——「这份证据是双流共享的」完全由悬挂位置与箭头方向说清，没有一根多余的线。
  • 收尾：Enhanced 特征堆（比输入端更艳的热力图）→ Fusion 小药丸 → Detection 大桃色盒（#FCDFCA），全图唯一的大面积暖色落在终点盒上，是管线层的视觉句号。

框架图 · 中带CIM 展开

  • 左半是流程式画法：Fvis/Fir 先画成「玻璃片堆」（线框立方里层叠的半透明薄片，蓝/灰分模态），合流进一根共享的 Efficient Downsampling 竖条，再分出 Q/K/V——三枚横置胶囊（渐变填充，蓝=源自 VIS、灰=源自 IR）配同色箭头；随后进入 Priority Attention 盒（盒身带多层片状轮廓，像一叠纸的上沿），经 Aggregation 竖条与两级 ⊕（浅蓝填充 #B9CAE0 的带圈十字）输出增强片堆。
  • 右半是符号式画法：同两个模块（VPAM/IPAM）重画为 MHA 图——下方两排竖置 token 胶囊（VIS 蓝渐变、IR 灰渐变），虚线横贯其上表示投影分界，V/K/Q 以彩色箭头（颜色随源模态）升入桃色金边 MHA 横杆（填充 #FCEBDD、描边 #BF9000），顶部输出四枚白底胶囊——可见优先一组绿描边（#789440）、红外优先一组紫描边（inferred 同族色）。
  • 同带两画法并置是本图最大胆也最易误读的决定（见 §07）。

框架图 · 下带IWM / EFM

  • IWM 是一条珠链：VIS Input 粉盒 → Conv 1 / MaxPool 1 / Conv 2 / MaxPool 2 / FC 1–3 / SoftMax 一串高窄竖芯片（文字旋转 90°，填充按类型轮换浅蓝/浅绿/浅黄），然后是全图的母题 glyph——一根白→黑渐变的小立方堆（Illumination Level），再经 Transform 分叉出 Wvis / Wir 两条输出。网络结构被压成一串可数的珠子，「小分类器」的轻量感一目了然。
  • EFM 是一条短链：VIS Input → Sobel → Conv 1–3 → Edge Map（白盒）→ Fusion 药丸，VIS Feature 与 IR Feature 两个小盒从上下夹入 Fusion，Final Feature 粉盒收尾。与上带的实拍边缘图呼应：同一「边缘」概念，带 1 给实物、带 3 给流程。

数据集图MFAD

  • 变量排序矩阵：6 列场景沿顶部光照渐变条由暗到亮排列（夜路 → 黄昏 → 室内停车场 → 雾夜 → 阴天街道……），列轴不是场景名而是光照值本身；行是模态：Visible、Infrared、Label（与 Visible 同图但带绿色标注框）、Edge（黑底白线）、Depth（灰度行＋jet 行双渲染同挂一签）。
  • 把 Label 与 Edge 当作与传感器模态平级的「行」，等于宣示这个数据集卖的不只是图、还有派生标注层；Depth 的一模两渲（灰度存真、jet 悦目）则把「数据可信度」与「展示效果」各给一行。
  • 全图无标题、无图注文字，组织信息全部压在顶部渐变轴与左侧旋转行标签里——极简，但阅读成本转嫁给了那排旋转 90° 的衬线字（见 §07 瑕疵）。

色彩拆解 measured

Colour System

色值以笔记实测表为准，均为程序采样实测（measured）；唯一例外是输出胶囊的紫描边——笔记标注为视觉估计（inferred，同族色、无采样色值），该卡不可点击、不冒充实测。IR 家族为中性灰阶、无单一色值，同样不可点击。点击任意实测色卡即可复制 HEX。

输出胶囊描边（紫）inferred紫 · 同族色（未采样）出处：红外优先组；视觉估计，无实测色值，不冒充实测
IR 家族中性灰阶出处：板片、胶囊、片堆均为灰渐变（视觉）

色彩系统分析

这是一套「填充让位、描边当家」的系统——模块填充全部压到近白粉彩（饱和度低于 002 期），色彩被转移到三处小面积位置：金描边（只给 MHA，标记「注意力在此」）、彩描边输出胶囊（绿/紫，标记「哪种优先的产物」）、渐变 glyph（光照立方堆与 token 胶囊的渐变本身即数据）。模态色只剩蓝/灰一对（VIS=蓝系、IR=灰系），贯穿板片、玻璃片、胶囊、箭头四种载体，是迄今各期里模态色执行最彻底的一套。代价：填充过淡，#EEEAF2 与 #EBF1DF 在印刷端与白底的界限只剩描边（见 §07）。

05

图形拆解

Visual Components
C-018

胶囊（stadium）

token 的专属形状，横置装 Q/K/V、竖置装 token 序列，一律带渐变（横置左深右浅、竖置下深上浅，像注了半管液体）。形状即类别：见到胶囊即知是 token，不需要文字解释第二次。

C-020

玻璃片堆

注意力输入画成线框盒里的层叠半透明薄片（蓝/灰分模态），与主干输出的 jet 热力图实堆形成「双堆方言」——同是特征，一个强调「可被注意的序列」（透、薄、齐），一个强调「已算出的响应」（实、艳、糙）。

板片三级跳

Backbone 三块板由大到小等比收分，是 001/002 期都用过的特征金字塔速记，此处板面是全图唯一上实色（#4B90BB）的位置，把「骨干」钉成视觉锚点。

C-019

证据插图

钟形曲线＋渐变条、实拍边缘图——把抽象量（光照等级、边缘先验）以「仪表照片」的形式实物化，尺寸虽小却是全图信息密度最高的两个小方块。

C-021

渐变立方堆

白→黑五段立方竖堆是「光照等级」的象形字——一个 glyph 同时是图标和量表（顶部插图里它与钟形曲线叠用，见 §07 的母题分析）。

⊕

带圈十字 ⊕

浅蓝填充（#B9CAE0）的 circled cross，比 002 期的细线 ⊕ 更粗更像按钮；残差的长黑线沿面板边缘走直角绕行（中带左半上下两条），把「跳连」画成面板的包边。

Conv→ Pool→ FC→ SoftMax
C-022

竖芯片珠链（IWM）

高窄圆角矩形＋旋转文字，把一段小网络画成可数的珠串；芯片填充按算子类型轮换，与 002 期「芯片色即算子」同族但更淡、更装饰化。

06

布局拆解

Layout & Composition
  • 三带分节：粗灰虚线（#7F7F7F）大圆角框三段全页——带 1 管线（全宽）、带 2 CIM（全宽，占高约 40%）、带 3 IWM（左 ~57%）＋EFM（右 ~43%）。带高按模块复杂度分配，CIM 作为头牌模块拿到整整一带，与带 1 里它只是个空盒形成互文：先给名字、再给整带展开（读者被「欠」了一次解释，又在下一带足额偿还）。
  • 带内镜像：上带双流上下镜像；中带右半两组 MHA 左右镜像；中带左半 VPAM/IPAM 上下镜像——全图三处镜像，皆是「双模态对称性」的版式化。
  • 中缝利用：上带双流之间的中缝不留白，挂证据插图（见 §03）；下带两模块之间的虚线缝则纯作分隔。同一「缝」，一处做内容、一处做标点。
  • 数据集图：矩阵＋单轴（顶部光照渐变条）＋旋转行标签；列无文字标题、行无刻度，光照轴是唯一的组织者。与 001 期 URMIF 数据集图的「非对称网格＋跨缝药丸」相比，这里是严格等距矩阵——数据集图的气质从「展板」变成「量表」。
07

精致感来源

Where the Polish Lives

  1. 光照母题的三次复现（本期最重要的发现）

    同一个「白→黑灰度渐变」母题出现三次、三种尺度——框架图上带的证据插图里，它是钟形曲线脚下的底座（光照的分布）；下带 IWM 里，它是 SoftMax 与 Transform 之间的立方堆（光照的取值）；数据集图里，它升格为整张图的列轴（光照的排序）。读者在框架图里认过两次，翻到数据集图时不需要任何文字就懂列的排法。把论文的核心变量做成贯穿全部图面的版式母题，是这篇图最值得学的一手（crops/framework-top-insets.png、crops/framework-iwm-chain.png）。

  1. 证据挂中缝

    光照曲线与边缘图各只画一份、悬在双流正中、双向箭头分供两支（crops/framework-top-insets.png）——比「每支各画一份」省一半墨，比「画在角落再引线」少两根线，还顺带把双流中缝这块天然留白用成了内容区。001 期 URMIF 的跨缝药丸标签是同一思想的标签版，这里是插图版。

  2. 箭头继承源模态色

    CIM 里源自 VIS 的量走蓝箭头、源自 IR 的走灰箭头（crops/framework-cim-left.png、crops/framework-cim-mha.png）——Qir 那根伸进 VPAM 的灰箭头不用读字就知道「这是跨模态来的 query」。箭头颜色从装饰升格为来源标注。

  1. 输出胶囊的「白身彩边」

    MHA 的输出 token 不再填色，只留白底＋彩边（绿/紫分优先方向）——与输入端的实填渐变胶囊形成「满入空出」的状态对照（crops/framework-cim-mha.png）。

  2. 金边的克制

    全图唯一的金属色 #BF9000 只描 MHA 横杆一处，注意力模块因此在满页粉彩里自带高光——与 002 期「红色配给制」同理，这里配给的是金色。

瑕疵（照实记）

  1. ①CIMs 巨石盒层级倒挂——管线层的核心模块是一个近乎空白的巨盒（#EEEAF2，写三个字占了全图约 8% 面积），而 Conv 1 这种小算子反而在下带得到完整展开；读者在管线层对系统拓扑的理解几乎全靠中带的偿还。
  2. ②同带两画法易误读——中带左半（流程式）与右半（符号式）画的是同两个模块，初读极易当成四个模块；图面没有任何「此二者为同一模块的两种视图」的标记。
  3. ③钟形曲线装饰化——光照插图的概率曲线坐标轴在印刷尺寸下不可读（纵轴字样糊成 PID 状），它作为「仪表」的 可信感大于信息量。
  4. ④填充过淡的印刷风险——#EEEAF2、#EBF1DF、#DDE7F2 三种主填充与白底的色差极小，低质量印刷或投影下模块边界将只剩细描边。
  5. ⑤数据集图行标签旋转 90°——Visible/Infrared/Label/Edge/Depth 需侧头读；且 Depth 一签挂两行（灰度＋jet）无子标注，Edge 行在大缩略下近乎全黑、易被当成空行或缺图。
  6. ⑥同一对象两种画法——边缘在上带是实拍图、在下带是 "Sobel" 文字芯片；Backbone 是 3D 板片而 Detection 是扁平大盒；抽象层级在带间不统一（与 ① 互为表里：这张图是「每带各画各的」拼装感最强的一期）。

09

设计总结

Takeaways · Transferable Techniques

可迁移技法 · 6 条：

  1. 核心变量母题化

    把论文最核心的变量（如光照）提炼成一个小 glyph（灰度渐变块），在框架图、模块图、数据集图里以不同尺度复现三次以上——读者学会一次，全文通用，这是「方法概念 → 版式母题」的直译法。

  2. 证据挂中缝

    双流共享的输入/先验只画一份，悬在双流中缝、双向箭头分供两支；中缝留白由此变内容区，还省掉一整套引线。

  3. 形状即类别

    给每类对象分配专属形状（胶囊=token、板片=骨干特征、玻璃片=注意力序列、圆角盒=模块），形状系统稳定后，文字标签只需出现一次。

  4. 箭头继承源头色

    多源汇流图里，箭头颜色随其来源走（蓝=源 A、灰=源 B），跨源的那根箭头不用读字即自明。

  5. 描边配给制

    当填充必须淡（大页面、高密度）时，把色彩预算转移到描边——一种贵重描边色（金）只给头牌模块，一组彩边只给输出端，层级照样成立。

  6. 变量排序矩阵（数据集图）

    数据集展示图的列不按场景名、而按数据集的核心变量（光照）排序，行把派生层（Label、Edge）与传感器模态同格并列——矩阵本身就是数据集卖点的论证。

跨期对照（与第 001、002 期）

本系列已拆各期的「语法载体」各不相同——URMIF 用线型、Fusion-Mamba 用芯片色、EI²Det 用形状（胶囊/板片/玻璃片各表一类）。布局上，EI²Det 与 Fusion-Mamba 同属「管线层＋展开层」的多层页面，但分节符从细黑虚线升级为粗灰虚线框，且展开层有两带。数据集图则与 001 期成对照：URMIF 是非对称展板（大小格＋跨缝药丸），EI²Det 是严格等距的量表矩阵（变量轴＋旋转行签）。母题复现（光照渐变 ×3）是本系列迄今独一份的手法——前两期的图各自成立，EI²Det 的两张图是靠母题互相解释的。
