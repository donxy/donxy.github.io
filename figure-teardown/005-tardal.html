02

整体观感

Overall Impression

前四期的共同气质是「克制的粉彩说明书」，这一期正好站在对面：信息图极繁主义。三张图用了七种图表体裁（气泡图、旭日图、面积直方图、3D 曲面图、等高线图、照片拼贴、层条码），全部饱和原色、全部衬线体、气泡带高光、模块带 3D 挤出、照片装进云朵——没有任何一处留白是「闲着的」，每块面积都被赋予一种图表职责。它的设计野心不在画一个网络，而在把整篇论文（方法＋数据＋性能）压缩成三条可视化横幅。

最值得记的一条系列线索：本文一作刘晋源正是第 001 期 URMIF 的一作。2022 年的 TarDAL 是极繁信息图，2026 年的 URMIF 是扁平粉彩双面板——同一位作者四年间从「什么都画、画满」走到「只画结构、画淡」，这一期因此同时是 TarDAL 的拆解和 URMIF 的前史（inferred）。

与 002–004 期的粉彩家族对照：那边的色彩是编码（芯片色即算子、胶囊色即类别），这边的色彩首先是情绪与注意力——TarDAL 的气泡用纯红 #D60D16 把自己从所有对手中拎出来，苹果用写实照片质感在一片矢量图里制造一个无法忽视的落点。编码当然也有（见 §07），但排序在「先抓住眼睛」之后。

逐图拆解

Figure by Figure

Fig. 1 · 三联信息图横幅论文的全部卖点，一行说完

  • 左 · 气泡图：每个方法一颗立体气泡（径向渐变＋左上高光＋底部投影），引线连到「方法名（衬线大字）＋Parameters＋出处年份（灰色小字）」三行标签。TarDAL 独占左上角——横轴最左（最快）、纵轴最高（最准），且只有它的气泡与名字是纯红色；其余方法按暖→冷散布。构图即论证：不需要读数字，「左上角的红点」已经说完结论（inferred）。
  • 中 · 旭日图：内圈四扇区是光照条件——Daytime 红、Night 绿、Challenge 蓝、Overcast 黄；中圈是场景大类，外圈是细分场景名，全部沿半径方向旋转排字，颜色随家族继承。四条引线给出各光照的图像数：1621 / 736 / 765 / 1078，四数之和恰为 4200，与 Table 1 的 M³FD 图像对总数一致（measured，图面数字加总核对）——旭日图不只是装饰，它是数据集的构成账本。
  • 右 · 双直方图：Infrared 在上、Visible 在下，同为四色堆叠面积，图例（Daytime 红 / Night 紫 / Overcast 青 / Challenge 棕）与旭日图内圈共用同一套光照色码（Daytime 在两处都是红色系，inferred 为有意复用）。两幅图的横轴都是 0–256 像素值，上下对齐让「两种模态的像素分布差异」可以直接竖读。
  • 三个面板之间没有任何连接线或共同坐标——并排本身就是版式：性能、构成、分布三种证据各占一格，读者从左到右扫一遍，正好走完「我更快更准 → 我的数据更全 → 我的数据分布更宽」的叙事顺序（inferred）。

Fig. 2(a) · 问题建模用一幅 3D 曲面把 bilevel 优化画成登山故事

  • 上行是「符号层」：约束公式、min 公式与两个 3D 挤出块——Fusion Φ 粉红 #F05D7B、Detection Ψ 紫 #8669AE，中间粗箭头标 u* 与 "Target-aware constrain"。Φ 与 Ψ 的粉/紫配色在 (c) 面板原样复现，是全图最稳定的双主角色码。
  • 下半幅是「隐喻层」：一整张浅蓝网格 3D 曲面（采样 #8DB9C6–#A8CFDB）占据面板约六成面积（inferred 目测），曲面上三条轨迹箭头——黄、绿、红——从峰顶沿不同路径下降，最终汇聚到谷底一颗写实红苹果上；图例写明：苹果 = Optimal Fusion Solution，紫色虚线弧 = Optimal Detection Solution。右侧竖排三张等高线小图（Φ / Ψ / Φ+Ψ）是同一故事的俯视图版本，苹果在其中缩成一个红点。
  • 这是本系列迄今最大胆的一笔：用一个照片质感的日常物体当数学最优点的图例符号。它不精确（曲面无坐标轴、无刻度），但它让「两个目标的解在此相遇」在一秒内可读——隐喻的沟通效率压过数据的精确性，是这张图的取舍宣言（inferred）。

Fig. 2(b) · 对抗网络云朵拼贴与放射式回路

  • 云朵即数据集：输入与输出不用矩形框，而用深蓝描边的云朵轮廓装照片拼贴——左上红外云（黑白照片）、左下可见光云（彩色照片）、右侧融合云（体量最大）。云朵的有机轮廓与照片的无序堆叠共同传达「这是一堆真实图像样本」，与规则的几何模块形成质感对位（inferred）。前景目标与背景细节则用小一号的云朵：金色描边云装红外行人裁片（Foreground Targets），浅蓝描边云装边缘图（Background Details）。
  • 色彩对位成系统：金色小云 → 金黄 Target Discriminator #FFCC5C，浅蓝小云 → 蓝色 Detail Discriminator #85A6D7——判别器的颜色与它审判的那类样本云同色（measured 色值比对＋inferred 设计意图），读者不用读字就知道哪条对抗线管前景、哪条管背景。
  • 中央生成器：Generator 橙块 #F2A35D 坐在面板正中，左接红外 X、可见光 Y 两根粗灰箭头，右出融合云；判别器分居右上、右下，融合样本以 "fake" 身份从右侧回送入判别器，源样本以 "real" 从左侧进入——对抗回路画成一个横置的环。两条弧形虚线反馈箭头（橙「Target adversarial」/ 蓝「Detail adversarial」）从判别器斜指回 Generator，标签随弧线倾斜排字。
  • 代价是阅读顺序：这张图没有单一方向的管线，眼睛要在「左云→中块→右云→上下判别器→弧线回中」之间跳读，是本期三图中导览最弱的一张（见 §07）。

Fig. 2(c) · 协同训练条把 (a) 的主角缩小，做成页脚式回环

  • 浅绿底 #F3F9F0 的细长条里，Φ 粉块与 Ψ 紫块以与 (a) 完全相同的造型与颜色再出现一次，中间 u* 粗箭头；下方粉色虚线从 Ψ 绕回 Φ（BP），红色实线正向（FP），图例在右下角；两行链式梯度公式填满中下空白。
  • 它的版式功能是收束：(a) 提问题、(b) 给网络、(c) 用一行回环把「联合训练」盖棺——三联面板构成「公式—网络—训练」的完整叙事，且 (c) 与 (a) 的视觉复用让首尾呼应（inferred）。

Fig. 3 · 层条码把网络结构压成一条 20 毫米高的规格带

  • 每个网络是一排竖芯片：Conv 浅蓝面＋藏青框 #284E94、BN 烧橙 #C55A11、ReLU 纯黄 #FFC200，三者捆成一组三联芯片，沿一条粗黑水平脊线重复；芯片内文字全部竖排 90°。
  • Generator 的 dense 连接只画在前段：红色直角折线弧（形如订书钉）从第一组上方跨到后续各组，绿色回弧从下方返回——连接拓扑直接画在条码上方，不另设图例。末端 Conv+Tanh（绿 #74AF4D）与前面板的紫框标记「输出组」。
  • Discriminator 极简：三组相同三联芯片＋一枚紫色 FC 芯片 #471865 收尾，与 Generator 的繁复形成同图内的密度对照（inferred）。
  • 整条规格带不标任何通道数、卷积核尺寸——它只承诺拓扑，不承诺尺寸（见 §07 瑕疵）。

图形拆解

Visual Components
C-023

云朵照片拼贴

以云朵轮廓（深蓝描边）为容器装多张照片的无序拼贴，表达「一堆样本」；派生小云朵（金边/浅蓝边）装派生数据（目标裁片/边缘图）。容器轮廓的有机感与内部照片的真实感互为表里。

C-024

损失曲面轨迹小品

3D 网格曲面＋多条彩色下降轨迹箭头＋谷底标记物，右侧附等高线俯视小图阵列（Φ / Ψ / Φ+Ψ 三联）。把抽象优化过程讲成「下山找落点」的空间故事。

C-025

写实图标当图例

用一颗照片级红苹果充当「最优融合解」的符号，图例行里苹果与虚线线型并列——写实 glyph 与抽象线型同级入例。本系列最出格的图形决定，记忆点与违和感同源。

C-026

旭日图数据集画像

三层旭日图（条件→大类→细类）＋放射旋转标签＋计数引线，把数据集构成画成一张可加总核账的环形图；内外层颜色家族继承。

层条码规格条

三联竖芯片（算子色码：Conv 藏青 / BN 烧橙 / ReLU 黄）沿粗黑脊线重复成「条码」，连接弧（红订书钉弧在上、绿回弧在下）直接叠印在条码上方；灰签标题（Generator / Discriminator）压在盒框左上角。一条 6.4:1 的窄带装下两个网络的全部拓扑。

其余图形语言：3D 挤出块（Φ/Ψ/Generator/判别器同一造型语法，顶面浅、正面饱和、右侧面深）；立体气泡（径向渐变＋高光＋投影，Fig. 1）；引线标签（气泡图与旭日图共用「细灰引线＋衬线标签」）；带引号的 "real" / "fake" 直接标在箭头上，用 GAN 的行话代替图例。

07

精致感来源

Where the Polish Lives

做得好的（本期精致感主要来自「系统性复用」，不是单点工艺）：

  1. 色码跨图复用

    Φ 粉 / Ψ 紫在 Fig. 2 的 (a)(c) 两面板原样重现；Daytime 红贯通 Fig. 1 的旭日图与直方图；判别器金/蓝与样本云金/蓝对应。三处复用让七种体裁不散架——这是极繁风格不翻车的唯一绳索，本文抓得很稳（measured 色值比对支持）。

  2. 旭日图可核账

    四条 Num 引线之和与 Table 1 总数严丝合缝（4200），装饰性最强的图同时是数据最实的一张。

  3. 隐喻的勇气

    苹果＋曲面在满是方块箭头的领域里制造了本系列第一个「过目不忘」的落点；四年后 URMIF 的克制反过来证明作者对这种勇气的收放都是有意的（inferred）。

  4. Fig. 3 的经济性

    两个网络的拓扑（组数、dense 连接、收尾层）在一条 20 毫米高的带子里交代完毕，芯片色码与脊线让它在缩略图尺寸下仍可辨认结构密度差异。

瑕疵（拆解不是吹捧，逐条记）

  1. ①气泡大小不编码任何可读变量（最实质的瑕疵）：DenseFuse 参数仅 74K 却是全图最大气泡，TarDAL 296K 的气泡小得多，RFN（10930K）的气泡干脆缩成 DenseFuse 大气泡里的一颗小蓝点，引线还互相交叉——第三维在这里是装饰，却伪装成数据。
  2. ②旭日图外圈标签大量旋转至倒置，下半圈场景名需转头阅读；Challenge 的引线注「Depending on the scene」含糊，与其余三条给确切数字的引线口径不一。
  3. ③3D 曲面无轴无刻度：占 (a) 面板约六成面积却不承载任何数值，只做隐喻；且苹果是位图写实图标，混在一张矢量图里边缘风格打架——记忆点与违和感是同一件事。
  4. ④Fig. 2(b) 导览弱：回路式布局没有入口标记，"real"/"fake" 箭头双向对射，初读时难以确定先看哪条线；云朵轮廓还把照片里的人物拦腰裁断，拼贴边缘毛糙。
  5. ⑤三面板三底色无说明：奶油/冷灰/青瓷绿的分区逻辑（理论/网络/训练）要靠读者自行归纳，图注未点明。
  6. ⑥Fig. 3 只给拓扑不给尺寸：无通道数、无卷积核、无组内层数标注；竖排 5–6 pt 级小字在印刷版单栏宽度下接近可读极限；Generator 的 dense 弧只覆盖前四组、后段裸线，细节密度前后不均。

09

设计总结

Takeaways · Transferable Techniques

可迁移技法 · 5 条：

  1. 首页横幅三联证据

    把「性能—构成—分布」三类证据做成一条通栏横幅放在摘要之前，读者在读任何文字前先被说服一半；前提是三格共用一套色码。

  2. 隐喻落点法

    抽象优化/目标用一幅空间隐喻（曲面＋轨迹）＋一个写实图标落点讲完，精确数据留给表格——图负责理解，表负责证据，分工明确时隐喻不算偷懒。

  3. 容器即语义

    云朵装样本、方块装模块、条码装层——容器形状本身先于文字说明内容类别；容器选得对，图例可以减半。

  4. 色码复用是极繁风格的纪律

    体裁越多，越要靠同一组颜色在不同图之间反复出现来缝合；没有复用，极繁即杂乱。

  5. 规格条备案

    次要网络结构不必占一整张图，一条芯片条码＋连接弧即可完成「可复现级拓扑备案」，把版面让给主图。

跨期对照

与第 001 期（URMIF，同为一作）对照，本期是「信息图极繁」的样本，001 是「扁平粉彩极简」的样本——两期合看是同一作者的风格迁移标本。与 002–004 期对照，本期证明粉彩不是唯一解：饱和原色＋多体裁在色码纪律下同样成立，但气泡尺寸这类「伪编码」是极繁风格最容易埋的雷。
